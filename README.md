# School Management System using Salesforce

## Project Overview

The School Management System is a Salesforce-based application designed to manage school operations such as student admission, student records, academics, faculty, attendance, examinations, marks, report cards, fees, and dashboards.

## Features

- Student Admission Management
- Student Management
- Academic Year, Class and Section Management
- Subject Management
- Faculty Management
- Timetable Management
- Attendance Management
- Examination Management
- Marks Management
- Report Card Generation
- Fee Management
- Parent Portal
- Student Portal
- Faculty Portal
- Reports and Dashboards

## Salesforce Features Used

- Standard Objects
- Custom Objects
- Master-Detail Relationships
- Lookup Relationships
- Record-Triggered Flows
- Email Alerts
- Approval Process
- Validation Rules
- Formula Fields
- Profiles
- Roles
- Permission Sets
- Sharing Rules
- Reports and Dashboards

## End-to-End Workflow

Campaign → Lead → Admission → Student → Class & Section Allocation → Faculty Assignment → Timetable → Attendance → Examination → Marks Entry → Result Calculation → Report Card → Email Notification → Portal Access → Fee Management → Reports & Dashboards

- Lightning Experience
